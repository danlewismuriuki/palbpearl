# ADR template

**Title:** Short, imperative description of the decision  
**Status:** accepted  
**Date:** YYYY-MM-DD  
**Owner:** Person or role accountable for this ADR

## Context

What problem, constraint, or opportunity led to this decision? Who is affected? What was true before this ADR?

## Decision

State the decision clearly in one or two paragraphs. Use **provisional** in this section if the decision is time-boxed or pending evidence.

## Alternatives considered

List credible options that were not chosen. For each, one line on why it was set aside.

## Consequences

### Positive

Benefits and simplifications this decision enables.

### Negative

Costs, limitations, or risks accepted.

### Follow-ups

Actions, ADRs, spikes, or documentation updates required next.

## Related

Relative links to other ADRs, architecture docs, or standards this decision touches.
