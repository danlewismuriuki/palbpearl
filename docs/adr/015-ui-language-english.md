# ADR-015: UI Language for the Demo — English

## Status
Accepted — 2026-11-19

## Context
The demo audience reviews the flow on desktop browsers in device mode.
Swahili labels read as unfamiliar or unfinished to that audience, and
the brief is written in English. Bilingual UI is a Phase 2 concern.

## Decision
All farmer-facing screens in the demo use English labels, English
error messages, and English success copy.

## Consequences
- ADR-014 is superseded.
- Replacing strings later is a string-table change, not a rewrite.
